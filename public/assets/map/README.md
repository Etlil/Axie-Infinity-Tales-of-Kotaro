# Dungeon selection vector assets

Original SVG artwork created for this project. These assets are used by the level-selection map, with responsive placement in `src/expedition-map.css`.

- `mosslight-grove.svg`: leafy forest shrine, roots, mushrooms, and three rune stones.
- `amber-quarry.svg`: amber crystals, mine entrance, rails, a cart, and counterweight crate.
- `sunken-sanctuary.svg`: flooded ruins, broken pillars, three tidal lights, and waterfalls.
- `journey-terrain.svg`: shoreline, grassy terrain, water ripples, and distant scenery.

The three landmarks use a `360 × 300` viewBox and transparent backgrounds. Their paths, colors, and groups can be edited directly or opened in a vector editor. Keep each landmark's proportions when resizing it. The terrain deliberately stretches to fill portrait and landscape map layouts. All artwork is decorative; level buttons and labels are separate accessible HTML controls.

No external images, embedded bitmaps, fonts, or third-party character artwork are included in these SVGs. The project's saved Axie reference sources remain in `docs/ASSET_REFERENCES.md`.
